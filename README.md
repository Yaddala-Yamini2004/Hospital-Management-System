# 🏥 Hospital Management System

A **Java-based Hospital Management System** developed to simplify and organize basic hospital operations such as managing patients, doctors, appointments, and hospital information.

This project demonstrates the use of **Object-Oriented Programming (OOP) concepts in Java** and provides a simple console-based approach to hospital management.

---

## 📌 Project Overview

The Hospital Management System is designed to manage essential hospital activities in a structured way.

The system allows users to:

* Manage patient information
* Manage doctor information
* Schedule and manage appointments
* Store hospital details
* Display patient and doctor information
* Organize hospital operations using Java classes and objects

The project focuses on applying **Java programming fundamentals and OOP principles** to a real-world problem.

---

## ✨ Features

### 👨‍⚕️ Doctor Management

* Add doctor information
* Store doctor ID, name, specialization, and other details
* Display doctor information

### 🧑‍🤝‍🧑 Patient Management

* Add patient information
* Store patient details
* Display patient records

### 📅 Appointment Management

* Create appointments between doctors and patients
* Store appointment details
* Display appointment information

### 🏥 Hospital Management

* Maintain hospital-related information
* Connect doctors, patients, and appointments
* Provide a structured representation of hospital operations

## 🧠 OOP Concepts Used

This project demonstrates important **Object-Oriented Programming concepts**:

* **Classes and Objects** – Represent real-world entities such as Hospital, Doctor, Patient, and Appointment.
* **Encapsulation** – Organizes data and related methods within classes.
* **Abstraction** – Represents essential hospital operations through classes and methods.
* **Inheritance** – Can be extended to represent relationships between different entities.
* **Object Interaction** – Different classes interact to perform hospital management operations.

## ⚙️ How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/Yaddala-Yamini2004/Hospital-Management-System.git
```

### 2. Open the Project

Open the project folder in **Visual Studio Code** or any Java-supported IDE.

### 3. Compile the Program

Open the terminal and run:

```bash
javac Main.java
```

If your classes need to be compiled together:

```bash
javac *.java
```

### 4. Run the Application

```bash
java Main
```
